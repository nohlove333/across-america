# Photograph credits

Each photo's exact author, capture date, original Wikimedia Commons file page and license URL are in ../../photo-data.js and displayed under the country-card image. All files are local WebP conversions fitted within 1200×1000 without editing the depicted content. Follow the linked CC BY / CC BY-SA / CC0 conditions when reusing. Corresponding new WebP files are offered under the same license as the original. The game code and other artwork do not inherit the photo licenses.
